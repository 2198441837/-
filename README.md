# 旅游景点推荐项目 🌏

一个基于Vue3开发的现代化旅游景点推荐网站，集成了精美的UI设计、丰富的交互功能和完善的用户体验。

## 🎯 项目特色

- **响应式设计** - 完美适配桌面端和移动端
- **现代化UI** - 采用渐变色彩和卡片式布局
- **丰富交互** - 景点详情弹窗、标签切换、搜索功能
- **用户系统** - 登录注册、收藏管理功能
- **单页应用** - 基于Vue3 Router的流畅页面切换
- **后端API** - Express服务器提供RESTful接口

## 🚀 快速开始

### 方法一：直接运行（推荐）

1. 直接双击 `index.html` 文件在浏览器中打开
2. 或者在项目目录中运行：

   ```bash
   # 启动本地服务器
   python -m http.server 8000
   # 然后访问 http://localhost:8000
   ```

### 方法二：使用Node.js后端服务

1. 确保已安装Node.js (版本 >= 14.0.0)

2. 安装依赖：

   ```bash
   npm install
   ```

3. 启动服务器：

   ```bash
   npm start
   ```

4. 访问：<http://localhost:3000>

## ⭐ 主要功能

### 🏠 首页

- **英雄区域** - 渐变背景的宣传横幅
- **景点网格** - 精美的卡片式景点展示
- **搜索功能** - 实时搜索景点名称、位置和描述
- **随机推荐** - 一键获取随机景点推荐

### 👤 用户系统

- **登录功能** - 简单的用户认证（演示用）
- **用户状态** - 登录状态持久化存储
- **个性化体验** - 根据登录状态显示不同内容

### 💎 景点详情

- **弹窗展示** - 优雅的模态框设计
- **标签切换** - 景点介绍、推荐路线、旅游贴士
- **丰富信息** - 详细介绍、主要景点、最佳时间
- **路线推荐** - 一日游、两日游等不同路线方案
- **旅游贴士** - 实用的旅行建议和注意事项

### ❤️ 收藏功能

- **一键收藏** - 快速收藏喜欢的景点
- **收藏管理** - 查看和删除已收藏的景点
- **数据持久化** - 收藏信息本地存储

### 🔍 搜索功能

- **实时搜索** - 输入即搜索，无需点击按钮
- **多字段搜索** - 支持按名称、位置、类型搜索
- **搜索高亮** - 清晰显示搜索结果
